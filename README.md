\# Task Manager (Command Line Python App)

This is a simple task manager app written in Python. It allows users
to: - Add tasks with priority and due date - Delete tasks by title -
View tasks sorted by due date or priority

\## ? How to Use

1\. Clone the repo or download the script: \`\`\`bash git clone
https://github.com/your-username/task-manager.git cd task-manager Run
the script:

bash Copy Edit python task_manager.py Follow the on-screen instructions
to:

Add a new task

Delete a task

View sorted tasks

Exit the program

? Task Format Each task is saved in a text file like this:

nginx Copy Edit task title \| priority \| YYYY-MM-DD ? Requirements
Python 3.x

? Notes This app stores tasks in a plain text file.

Tasks are displayed in a user-friendly format using terminal
input/output.
